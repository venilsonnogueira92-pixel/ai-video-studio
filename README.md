# AI VIDEO STUDIO

Um estúdio de criação de vídeos com inteligência artificial.

## Objetivo

Criar vídeos de até 10 minutos com:

- Personagem personalizado
- Narração em português brasileiro
- Animações e movimentos de câmera
- Imagens e cenas
- Legendas sincronizadas
- Música e efeitos sonoros
- Exportação em MP4 Full HD

## Tecnologias

- Python
- MoviePy
- gTTS
- Pillow
- NumPy

## Projeto em desenvolvimento

Este projeto está sendo desenvolvido para facilitar a criação de vídeos com inteligência artificial.
